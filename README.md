# Asset Management System

Web-based asset management system developed for internal use by the Faculty of Industrial Education and Technology. The system helps asset officers and authorized staff manage, track, and maintain faculty assets efficiently.

## Features
- Asset management (Create, Read, Update, Delete)
- Role-based access control (RBAC)
- Secure authentication and authorization
- RESTful API for frontend-backend communication
- User-friendly interface for asset tracking and management

## Tech Stack

**Frontend:**
- React.js
- HTML
- CSS
- Tailwind CSS

**Backend:**
- Node.js
- Express.js

**Database:**
- PostgreSQL

## System Architecture
Frontend (React) communicates with Backend (Node.js/Express) via RESTful APIs, and the backend manages data stored in PostgreSQL.
